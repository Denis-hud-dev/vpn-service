Поддержка и подключение

Начните с кабинета

Войдите в тот же аккаунт, которым оформляли заказ. Проверьте статус подписки и откройте «Подключиться через Happ». Выберите Android, iPhone, Windows или macOS на персональной странице; следуйте её инструкции импорта.

Оплата подтверждена, доступа пока нет

Повторите проверку статуса позже. Не оплачивайте заказ повторно ради ускорения выдачи. При продлении существующий профиль сохраняется.

Обращение по тестовому стенду

Для связи используется уже существующий тестовый бот @KudaVPN_Test_Bot. Раздел предназначен для поддержки и управления доступом; внешняя покупка в боте не включена.

Не отправляйте пароли, токены, полную ссылку Happ, CVC или данные карты. Достаточно времени операции, суммы, состояния заказа и описания проблемы. Реальный контакт поддержки и сроки ответа владелец утвердит до продаж.

Чеки НПД

Квитанция ЮKassa не заменяет чек «Моего налога». В локальной демонстрации чеки не формируются. После запуска состояние выдачи будет отражаться в истории покупок.
