# KudaVPN: один оригинал

`original.jpeg` — файл владельца `photo_2026-10-29 23.16.30.jpeg`, сохранённый побайтово. Размер 1254×1254, SHA256 `084ba43d6f5cd0ae8e51c6896db141dd9c78f0d80807917ef8917becaeda2337`.

Все остальные изображения создаёт `scripts/build_brand_assets.py` из этого единственного источника. Только пропорциональное уменьшение полного кадра и центрирование на чёрных полях; никакой перерисовки, вырезания букв/надписи, удаления фона, SVG-реконструкции, новых шрифтов, фильтров или изменения цветов. Исходный непрозрачный фон тоже является частью оригинала.

| Файл | Назначение |
|---|---|
| logo-512.png | Сайт, вход и страница Happ |
| logo-192.png | Компактный логотип и дополнительная иконка |
| telegram-welcome.png | 1280×720, весь квадратный исходник с боковыми полями |
| description-640x360.png | BotFather, строго 640×360 |
| avatar-1024.png | Подготовленная аватарка; metadata-конфигурация также может использовать оригинальный JPEG |
| favicon-32/64/128.png, favicon.ico | Полный логотип с полями; не отдельная вырезанная буква K |
| manifest.json | Размеры, координаты полного исходника и SHA256 результатов |

Установите зависимости разработки из `bot/requirements-dev.txt`, затем выполните `python scripts/build_brand_assets.py`. Проверка без записи: `python scripts/build_brand_assets.py --check`. Результаты генерации сохраняются в Git, Pillow не требуется на сервере для отображения.

Все три веб-приложения и бот используют `bot/branding.py`. Старые URL оригинального JPEG и вырезанной эмблемы оставлены совместимыми: сервер отдаёт по ним текущий полный оригинал/его пропорциональную копию. Старые файлы и генератор составного баннера удалены. Не создавайте отдельные независимые логотипы в static или bot/assets.

Ни генерация, ни изменение файлов не обновляют Telegram/BotFather или серверы. Для этого требуется отдельное согласованное развёртывание. Исторические сообщения Telegram не перезаписываются.
