# KudaVPN: утверждённый прозрачный PNG

Единственный эталон — original.png, файл владельца «Киберлоготип KudaVPN с неоновым глобусом.png», сохранённый побайтово. Размер 1367×1151, RGBA, SHA256 ea8160b3667452aceac8b3939308046dcf2585c57fd4f78d98f47bf84d5547d4. Прежний квадратный JPEG больше не является эталоном и удалён из текущих ресурсов.

Настоящая прозрачность: alpha 0…254, 649621 прозрачный пиксель и 923796 пикселей полупрозрачного изображения/свечения. CSS blend/mask/filter для имитации прозрачности не используются.

| Файл | Назначение |
|---|---|
| logo-512.png, logo-1024.png | Полный логотип в естественных пропорциях, RGBA |
| k-symbol.png | K, выделенная из пикселей оригинала, без перерисовки |
| logo-192.png | Прозрачная K с полями для компактных элементов |
| favicon-32/64/128.png, favicon.ico | Прозрачная компактная K |
| telegram-welcome.png | 1280×720, полный логотип, включая надпись, орбиту, замок и линии |
| description-640x360.png | Полный логотип, строго 640×360 для BotFather |
| avatar-1024.png, avatar-1024.jpg | K на тёмно-синем фоне; JPEG для существующего profile helper |
| legacy-logo.jpg | Технический ответ старого JPEG URL, не используется новыми HTML-шаблонами |
| manifest.json | SHA256, размеры, тип источника и параметры выделения/преобразования |

scripts/build_brand_assets.py использует пропорциональное уменьшение и центрирование. Для K разрешён выбор области исходных пикселей: контур/рамка записаны в manifest, восьмипиксельный запас сохраняет светящуюся кромку. RGB не перерисован, внутренние детали сетки/свечения остаются исходными. Векторной реконструкции и генерации изображений нет.

Веб-ресурсы и favicon сохраняют alpha. Только технические изображения Telegram photo/profile и старого JPEG URL сведены на фон #040a17: это реальные растровые файлы для старого помощника/фото, а не имитация прозрачности. Сайт использует прозрачные PNG. Эталон остаётся неизменным RGBA PNG.

После установки dev-зависимостей: python scripts/build_brand_assets.py; проверка без записи — python scripts/build_brand_assets.py --check. Pillow для отображения на сервере не нужен. Общий реестр — bot/branding.py, общий баннер — WELCOME_BANNER.

Изменение файлов не обновляет Telegram/BotFather или серверы. Реальные API-вызовы профиля и развёртывание требуют отдельного согласования. Исторические сообщения Telegram не переписываются.
