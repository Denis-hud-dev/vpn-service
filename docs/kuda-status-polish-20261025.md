# Компактный Kuda Status

Ветка `codex/kuda-status-polish-20261025` поверх Draft PR №23. Только интерфейс premium-кабинета: короткий статус, сохранённый тариф, динамический остаток, дата UTC (полное время сохраняется в «Моя подписка»), подтверждённые имена серверов. Страна не добавляется: подтверждённого поля страны в используемом read model нет. Доступность означает свежую серверную проверку и действующий персональный доступ из существующей проверки feed; доступность с конкретного телефона проверяет Happ.

Главные действия: «Подключиться» (поддерживаемый primary), «Продлить подписку», парные «Моя подписка» / «Мои устройства», «Управление», «Назад». В «Управлении» собраны существующие история, трафик, оплата/автопродление, подарки и приглашения. Неработающие возможности продолжают честно сообщать о недоступности. Новых операций нет. Нижняя ReplyKeyboard и гибридная навигация не меняются. Произвольные цвета сообщений и кнопок не устанавливаются; фирменные custom emoji сохранены.

Тариф и срок берутся из snapshot базы; цены и платежные обработчики не изменены. Если snapshot устарел и дата уже прошла, экран не показывает активную подписку или доступный сервер. Это только представление, без записи в базу. Отсутствующие данные обозначены явно. Продление ведёт к прежнему выбору тарифов без автоматического заказа; сохранение оплаченного времени проверяется существующим lifecycle-тестом на имитации событий.

Профильные проверки: состояния подписки, динамический срок, отсутствие фиктивной страны/доступности, HTML escaping, раздел управления и возвраты, ссылка Happ, отсутствие платежа от перехода «Продлить»; регрессии ReplyKeyboard, /start, уведомлений, EROFS и lifecycle. Полный локальный аудит не запускался. CI проверяется до развёртывания.

План обновления: git archive проверенного коммита, новый release только test bot; закрытая копия unit и drop-in 95/96, сравнение копий, сохранение старого release и готовый rollback. Переключается только WorkingDirectory test bot, без миграций и изменения приватной конфигурации. При ошибке readiness/postcheck — вернуть прежний drop-in и перезапустить только test bot. Feed, production, VPN, подписки и платежи не меняются.

Владельцу на Mac/Android: /start → «Личный кабинет»; проверить компактность и реальные поля; «Управление» → история/назад; «Подключиться» → прежняя страница Happ; «Продлить подписку» → только тарифы, без создания оплаты. Уведомления должны остаться в истории, нижняя клавиатура — под полем ввода.

Фактические PR, CI и результат обновления будут добавлены после выполнения.
