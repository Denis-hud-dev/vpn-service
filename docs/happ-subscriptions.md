# Персональные подписки Happ — локальная реализация

Официальный формат: https://www.happ.su/main/dev-docs/app-management
и https://www.happ.su/main/dev-docs/examples-of-links-and-parameters
Ответ text/plain содержит строки VLESS REALITY + Vision; заголовки profile-title,
profile-update-interval и subscription-userinfo сообщают имя, обновление и срок.
Интервал — рекомендация приложению, не гарантия мгновенного обновления.

Миграция 0004 добавляет subscription_tokens, vpn_nodes и node_access; 0005 —
версионированные намерения доступа, 0006 — таблицу node_health. Миграции
добавляют данные без удаления прежних записей.
WireGuard-таблицы и старые данные не меняются. Администратор добавляет узлы через
доверенный backend; удаления выполняются disabled, чтобы сохранить записи для
отзыва уже выданных UUID. Приватные REALITY-ключи и административные credentials
не хранятся в этих таблицах. UUID доступа являются секретами: доступ к таблицам
и резервным копиям должен быть ограничен.

HappService.issue(subscription_id) возвращает ссылку один раз. В БД только SHA256
случайного 256-битного токена. Доступ возможен лишь при active, будущем expires_at
и succeeded платеже, применённом через историю. Каждый узел имеет отдельный UUID.
Добавление узла после подтверждения адаптером появляется по прежней ссылке.
Отключение узла исключает его немедленно из выдачи и запускает отзыв при сверке.
Ссылку нельзя восстановить из хэша: повторно показывать в Telegram можно только
после явного отзыва/ротации. Для сохранения прежней ссылки в интерфейсе потребуется
зашифрованное хранилище с отдельным ключом или иной безопасный UX.

NodeReconciler проверяет желаемое состояние каждые 30 секунд в отдельном процессе
API. Истечение проверяется по часам независимо от статуса в БД. Блокировка,
истечение и отзыв токена вызывают gateway.apply(enabled=False). Ошибки повторяются;
UUID фиксируется до удалённой операции, чтобы сбой подтверждения не потерял доступ,
который нужно удалить. Ротация запрещена до подтверждения удаления старых UUID.

Адаптер HTTPSNodeGateway и агент Xray реализованы, но по умолчанию не подключены к
production. Управление доступом идёт по mTLS. Агент хранит краткосрочную аренду
локально и удаляет UUID по истечении срока даже при потере связи с центром.
На тестовом Xray проверены добавление и отзыв новых подключений; прекращение
уже открытой сессии сразу после отзыва не подтверждено. Развёртывание и проверка
на действующем узле требуют отдельного решения.

NodeHealthMonitor каждые 30 секунд проверяет доступность агента, Xray API и
локального TCP-listener. Список Happ исключает узлы без успешной проверки за
последние 90 секунд, с изменившейся конфигурацией и с истёкшей подтверждённой
арендой доступа. Сбой одного узла не скрывает остальные. Это проверка состояния
узла, а не доказательство его доступности из России и выхода в интернет; перед
публикацией узла всё ещё нужен реальный клиентский тест по маршруту пользователей.

Локальная точка запуска: python -m bot.subscription_api.main
Не запускать с production DATABASE_URL. Нужна отдельная мигрированная тестовая БД.
Переменные: DATABASE_URL, SUBSCRIPTION_PUBLIC_URL=https://имя-домена,
SUBSCRIPTION_TLS_CERT, SUBSCRIPTION_TLS_KEY, SUBSCRIPTION_PORT (18443 по умолчанию).
TLS обязателен, слушает только loopback. Публичный ingress/DNS/сертификат и Docker
этого сервиса ещё не развёрнуты; TCP 443 production уже занят Xray.
Бот не запускается и его health-сервер не используется. API по умолчанию работает
с отключённым адаптером узлов. Сервис не меняет статусы подписок, а проверяет право
на доступ при каждой выдаче и сверке.

URL — bearer secret: не логировать пути /s/* в reverse proxy, CDN, APM и HTTP
клиентах; не включать shared caching. Ответы no-store и no-referrer. Access log
в штатной точке запуска отключён. Перед публикацией нужны rate limiting,
проверка TLS/domain, ограничение ролей БД и monitoring без URL/UUID.

Telegram пока не интегрирован. Нужны команды получения/отзыва ссылки, проверка
владельца subscription_id, безопасная доставка без обычных логов, UX ротации,
настоящая ЮKassa-верификация и проверка импорта Happ на Android/iOS.
