# Kuda Orbit и гибридная история — подготовка тестового интерфейса

Ветка `codex/kuda-orbit-hybrid-20261023` основана на `codex/premium-ui-2-20261023` (Draft PR #19). Изменения ведутся в Draft PR #20. Основной бот, VPN, база production и действующие платежи не затронуты.

## Telegram

- Навигация использует существующее единственное актуальное сообщение. `/start` заменяет старый навигационный экран; если Telegram не даёт удалить его, экран обезличивается и появляется новый. Подтверждения реальных платежей, продления и истечения отправляются отдельным существующим механизмом `PremiumNoticeService`, который использует журнал событий для защиты от дублей. Вызовы меню не отправляют таких уведомлений.
- В тестовом премиальном кабинете и экране подписки добавлена «История подписки». Чтение ограничено Telegram ID владельца и возвращает только записанные в БД переходы состояния и сроков. Идентификаторы платежей и личные ссылки не выводятся. При отсутствии записей показано именно отсутствие записей; история платежей и чеки помечены как недоступные.
- Предложены **только для просмотра** стартовые цены 190 ₽/месяц, 490 ₽/3 месяца (экономия 80 ₽), 1690 ₽/12 месяцев (экономия 590 ₽). Кнопок оплаты для них нет. Реальные тестовые тарифы и суммы заказа остаются 299/799/2490 ₽. Зелёный и синий переданы символами 🟢 и 🔵, популярность — ⭐: Telegram не позволяет произвольно окрашивать фон сообщения или отдельную кнопку.

## Страница подключения

Оригинальный JPEG KudaVPN оставлен без изменений. Для страницы из него подготовлен отдельный прозрачный PNG `kudavpn-orbit-emblem.png`: узнаваемые геометрическая K, глобус и одна тонкая голубая орбита без встроенной подписи и чёрного квадрата. Дополнительные CSS-кольца и маскирование удалены; надпись KudaVPN Premium — отдельный текст. Страница сохраняет прежний безопасный механизм копирования личной HTTPS-ссылки и локального построения QR. Новый внешний сервис для QR или передачи ссылки не используется. Нет движущихся эффектов; настройка уменьшения анимации поддерживается остальной страницей. Изображение загружается с того же хоста.

Предпросмотр без действующих ссылок: [Mac](screenshots/kuda-orbit-desktop.jpg), [Android 390 px](screenshots/kuda-orbit-android.jpg). Снимки сняты с фиктивной ссылкой на `preview.invalid`; она не даёт доступ к VPN.

## Проверки

- Профильные тесты: 67 passed, 3 skipped. Отдельные серверные тесты страницы: 3 passed (для локального loopback потребовался запуск вне песочницы).
- Проверены вручную в локальном браузере Mac 1280×800, Android 390×844 и iPhone 430×932: композиция знака, первый экран, адаптивность, блок подписки, шаги подключения, копирование и раскрытие QR. Физический Android и Telegram UI в этой ветке ещё не проверялись.
- Владелец разрешил развёртывание только тестового бота и HTTPS-страницы. Перед переключением требуются проверенный SSH-доступ, резервная копия только тестовых компонентов и обратимый откат. Новые цены остаются предварительными и не должны попадать в платёжный checkout до отдельного решения.

## Изолированное развёртывание 23 октября 2026

Коммит `9907538` опубликован в [Draft PR №20](https://github.com/Denis-hud-dev/vpn-service/pull/20) поверх PR №19; [CI](https://github.com/Denis-hud-dev/vpn-service/actions/runs/40008883348) завершился успешно. Host key JustHost сверен с ранее подтверждённым официальной консолью отпечатком, вход выполнен существующим административным ключом. До переключения тестовые bot/feed были активны, `/ready` бота отвечал `200`, неверный `/connect/invalid` — `404`; рабочие Xray-процессы на 443/8443/9443/10443 зафиксированы.

Закрытая копия двух тестовых приложений, их unit-файлов и drop-in-конфигураций сохранена в `/opt/kudavpn-telegram-pilot/backups/kuda-orbit-9907538-20261023/` с правами каталога `0700`. Исходные рабочие каталоги оставлены неизменными. Новые отдельные каталоги `app-orbit-9907538-bot` и `app-orbit-9907538-feed` содержат только изменения интерфейса. Сценарий отката — `/root/kuda-orbit-rollback-9907538.sh`: он убирает два новых drop-in-файла и перезапускает только тестовые bot/feed, возвращая старые рабочие каталоги. Его синтаксис проверен; запускать только при необходимости.

Переключены **только** `kudavpn-telegram-pilot-bot.service` и `kudavpn-telegram-pilot-feed.service`. Обе службы активны, перезапусков после переключения `NRestarts=0`, `/ready` отвечает `200`, новый PNG отдаётся с действующим TLS и верной контрольной суммой, неверная личная страница возвращает `404`. Проверка реальной личной подписки владельца без вывода токена дала `200`, ровно одну строку VLESS с тестовым узлом 10443; личная страница дала `200`, содержит новый знак и кнопку копирования. В свежих журналах двух тестовых служб ошибок уровня `err` нет. Слушатели и PID Xray на 443/8443/9443/10443 совпадают с зафиксированными до обновления; серверные настройки, VPN и платёжные суммы не менялись.

Физическую навигацию и визуальный результат в Telegram/браузере Android проверяет владелец: `/start` → «Подключить VPN» → страница, затем «Кабинет» → «История подписки», «Тарифы» → предложения «Скоро», Kuda Smart → «Назад». Автоматического переключения Happ и изменения реального checkout здесь нет.

## Полировка Orbit

Утверждённый прозрачный знак остался неподвижным. Поверх его существующей орбиты движется только маленькая световая точка с циклом 18 секунд; при включённом уменьшении анимации она скрыта. На первом экране добавлена кнопка «Подключить VPN», ведущая плавной прокруткой к выбору платформы. Кнопка копирования, локальный QR и инструкции Happ не менялись; автоматический импорт не заявлен.

Предпросмотр с фиктивной ссылкой: [Mac](screenshots/kuda-orbit-motion-mac.png) и [Android 390 px](screenshots/kuda-orbit-motion-android.png). Проверены ширины 1280, 430, 390 и 320 px; переход по кнопке и раскрытие QR. Профильные тесты: 9 passed. Физическое отображение на Android и iPhone остаётся для проверки владельцем.

Для тестового HTTPS-сервиса сделана закрытая копия приложения, unit-файла, drop-in и списка исходных VPN PID в `/opt/kudavpn-telegram-pilot/backups/kuda-orbit-motion-ecf526d-20261023/`.
