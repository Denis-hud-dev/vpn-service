# Kuda Orbit и гибридная история — подготовка тестового интерфейса

Ветка `codex/kuda-orbit-hybrid-20261023` основана на `codex/premium-ui-2-20261023` (Draft PR #19). Изменения ведутся в Draft PR #20. Основной бот, VPN, база production и действующие платежи не затронуты.

## Telegram

- Навигация использует существующее единственное актуальное сообщение. `/start` заменяет старый навигационный экран; если Telegram не даёт удалить его, экран обезличивается и появляется новый. Подтверждения реальных платежей, продления и истечения отправляются отдельным существующим механизмом `PremiumNoticeService`, который использует журнал событий для защиты от дублей. Вызовы меню не отправляют таких уведомлений.
- В тестовом премиальном кабинете и экране подписки добавлена «История подписки». Чтение ограничено Telegram ID владельца и возвращает только записанные в БД переходы состояния и сроков. Идентификаторы платежей и личные ссылки не выводятся. При отсутствии записей показано именно отсутствие записей; история платежей и чеки помечены как недоступные.
- Предложены **только для просмотра** стартовые цены 190 ₽/месяц, 490 ₽/3 месяца (экономия 80 ₽), 1690 ₽/12 месяцев (экономия 590 ₽). Кнопок оплаты для них нет. Реальные тестовые тарифы и суммы заказа остаются 299/799/2490 ₽. Зелёный и синий переданы символами 🟢 и 🔵, популярность — ⭐: Telegram не позволяет произвольно окрашивать фон сообщения или отдельную кнопку.

## Страница подключения

Оригинальный JPEG KudaVPN оставлен без изменений. Для страницы из него подготовлен отдельный прозрачный PNG `kudavpn-orbit-emblem.png`: узнаваемые геометрическая K, глобус и одна тонкая голубая орбита без встроенной подписи и чёрного квадрата. Дополнительные CSS-кольца и маскирование удалены; надпись KudaVPN Premium — отдельный текст. Страница сохраняет прежний безопасный механизм копирования личной HTTPS-ссылки и локального построения QR. Новый внешний сервис для QR или передачи ссылки не используется. Нет движущихся эффектов; настройка уменьшения анимации поддерживается остальной страницей. Изображение загружается с того же хоста.

Предпросмотр без действующих ссылок: [Mac](screenshots/kuda-orbit-desktop.jpg), [Android 390 px](screenshots/kuda-orbit-android.jpg). Снимки сняты с фиктивной ссылкой на `preview.invalid`; она не даёт доступ к VPN.

## Проверки

- Профильные тесты: 67 passed, 3 skipped. Отдельные серверные тесты страницы: 3 passed (для локального loopback потребовался запуск вне песочницы).
- Проверены вручную в локальном браузере Mac 1280×800, Android 390×844 и iPhone 430×932: композиция знака, первый экран, адаптивность, блок подписки, шаги подключения, копирование и раскрытие QR. Физический Android и Telegram UI в этой ветке ещё не проверялись.
- Владелец разрешил развёртывание только тестового бота и HTTPS-страницы. Перед переключением требуются проверенный SSH-доступ, резервная копия только тестовых компонентов и обратимый откат. Новые цены остаются предварительными и не должны попадать в платёжный checkout до отдельного решения.
