# Тестовые тарифы KudaVPN Premium — 199 ₽

Изменение только для изолированного Premium/test checkout. Действующие 3 и 12 месяцев остаются **799 ₽ и 2490 ₽**. Новый месячный тариф — **199 ₽** с отдельным ID `pilot_month_199`. Основной каталог `TARIFFS` и исторический `month` за 299 ₽ не изменены: старые заказы должны сверяться по первоначальной цене, а старые подписки — сохранять правдивое название купленного тарифа.

Раздел и кнопки предварительных стартовых тарифов удалены. Старые callback `nav:launch_tariffs` / `launchplan:*` безопасно возвращают к текущему каталогу, не показывают preview и не создают платёж. Старый `paytest:month` в Premium тоже возвращает к выбору тарифа. Для нового заказа требуется явное подтверждение нового тарифа.

Кнопки текущих тарифов: `success` для месяца, `primary` для 3/12 месяцев. Это штатные именованные стили Bot API, а не HEX-цвета или замена фона эмодзи. Подтверждено [документацией Telegram](https://core.telegram.org/bots/api#inlinekeyboardbutton); локальная aiogram 3.31.0 имеет настоящее поле `style`. Существующий fallback Navigation сохраняет читаемые обычные кнопки, если сервер Telegram отвергает стиль. Старый клиент может не отобразить цвет: точные оттенки зависят от темы/клиента. Mini App для поддерживающих клиентов не требуется; для гарантированного собственного оформления на старых клиентах нужен отдельный Mini App, который здесь не создаётся.

Новый каталог явно передаётся checkout только при включённой конфигурации тестового Premium-бота. Обычный checkout по умолчанию не принимает новый ID. Повторные нажатия используют один заказ; старый pending на 299 ₽ не переиспользуется для 199 ₽. Проверка провайдера, однократное применение оплаты и продление сохранены. Никаких новых реальных или тестовых платежей при разработке/развёртывании не создавать.
