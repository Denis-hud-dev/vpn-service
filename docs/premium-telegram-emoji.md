# KudaVPN Premium — демонстрационный набор custom emoji

Статус: **демо, не опубликован и не подключён к ботам**. Ветка `codex/premium-emoji-demo` отделена от работающего контура. Исходники и экспорт находятся в `assets/telegram-emoji/`.

## Визуальная система

«Quiet Current»: собственный знак KudaVPN в виде графитовой скруглённой плитки с тонким контуром, центральным линейным символом и движущейся голубой точкой орбиты. Палитра: графит `#111A22`, электрический голубой `#55D6FF`, ледяной светлый `#D9F7FF`, приглушённый контур `#315165`. Плитка остаётся узнаваемой и в светлой, и в тёмной теме Telegram. Движение длится 2 секунды, повторяется без вспышек, символ остаётся читаемым в покое.

Для каждого элемента есть редактируемый `source/<имя>.svg`, прозрачный статический `png/<имя>.png` и анимированный `webm/<имя>.webm`. `preview/index.html` показывает реальные WebM в цикле; `preview/contact-sheet.png` и `preview/animated-grid.gif` — обзор набора. GIF служит только для предпросмотра, загружать в Telegram нужно WebM. `manifest.json` содержит имена, alt-emoji и параметры без Telegram ID и секретов. SVG и PNG — исходник и резервный вариант, **не замена** анимированному WebM.

## Проверенные требования Telegram

Выбран официальный формат video custom emoji: `.webm`, VP9, ровно **100×100 px**, до **30 FPS**, максимум **3 секунды**, до **256 КБ**, без звука, с цикличным движением. Набор экспортирован с 24 FPS и 2 секундами; проверка декодирования, прозрачности и движения проходит для 14 из 14 файлов. Telegram поддерживает и векторный `.tgs`, но он требует иной специализированной цепочки экспорта; этот набор поставляется как полноценный WebM-вариант, а не как неподтверждённый `.tgs`. Источники: [официальные требования к WebM](https://core.telegram.org/stickers/webm-vp9-encoding), [общая документация с разделом Custom Emoji](https://core.telegram.org/stickers).

Проверить или пересобрать локально (Python 3.12+ и FFmpeg через официальный пакет `imageio-ffmpeg`; без доступа к серверу и токенам):

```bash
python3.12 -m venv .venv-emoji
.venv-emoji/bin/pip install -r assets/telegram-emoji/requirements-build.txt
.venv-emoji/bin/python scripts/generate_premium_emoji.py
.venv-emoji/bin/python scripts/build_premium_emoji_preview.py
.venv-emoji/bin/python scripts/verify_premium_emoji.py
```

## Публикация через @Stickers

1. В официальном [@Stickers](https://t.me/Stickers) создайте **набор custom emoji**, а не обычных стикеров. Интерфейс доступен как мини-приложение и через команды; подписи могут меняться между версиями Telegram.
2. Загрузите 14 файлов из `assets/telegram-emoji/webm/` как файлы исходного качества. Для каждого выберите обычный emoji из таблицы как смысловую привязку. Не загружайте PNG вместо WebM, если нужна анимация.
3. Задайте название «KudaVPN Premium — Quiet Current» и доступное короткое имя набора. До публикации проверьте проигрывание, прозрачность и читаемость на Android в светлой и тёмной теме.
4. После публикации получите `custom_emoji_id` для каждого файла через Telegram/Bot API `getStickerSet` или `getCustomEmojiStickers`, сохраните карту ID → назначение в **отдельной** конфигурации тестового бота. Только после согласия владельца внедряйте в `@KudaVPN_Test_Bot` и проверяйте на устройстве.

Создание собственного набора доступно всем, однако добавление и использование custom-наборов Telegram относит к функциям Premium; условия показа ботом см. ниже. Набор здесь **не отправлялся** в @Stickers.

## Где значки допустимы в боте

- **Inline-кнопки и кнопки reply-клавиатуры:** Bot API 9.4+ поддерживает отдельное поле `icon_custom_emoji_id` перед текстом. Telegram ограничивает его использованием ботом с дополнительным именем, купленным на Fragment, либо сообщениями, которые бот непосредственно отправляет в личные/групповые чаты, если владелец бота имеет Telegram Premium. Установленный в проекте `aiogram 3.31.0` знает это поле, но публикации набора и проверки права владельца ещё нет. До подтверждения условий оставить обычный Unicode emoji или текст.
- **Текст и подписи сообщений:** `MessageEntity` типа `custom_emoji` / поддерживаемая HTML-разметка после получения ID; обязательна обычная emoji-замена. Не вставлять выдуманный ID. [Bot API](https://core.telegram.org/bots/api#messageentity), [custom emoji](https://core.telegram.org/api/custom-emoji).
- **Список команд `/` (`BotCommand`):** отдельного поля для custom emoji нет. Оставить короткие текстовые названия и описания. **Постоянная MenuButtonWebApp:** есть `text` и `web_app`, но отдельного поля custom emoji нет; брендовый знак поместить внутрь веб-страницы. [BotCommand](https://core.telegram.org/bots/api#botcommand), [MenuButtonWebApp](https://core.telegram.org/bots/api#menubuttonwebapp).
- **Фирменная страница KudaVPN Premium:** может использовать SVG/WebM как локальные ресурсы после отдельного согласования; это не означает автоматическое появление custom emoji в Telegram.

Даже когда API допускает значок, конкретный клиент Telegram может по-своему воспроизводить анимацию или учитывать настройки уменьшения движения. Физическая проверка кнопок на Android отложена до публикации набора и разрешения на тестовую интеграцию. Источник ограничений кнопок: [Telegram Bot API `InlineKeyboardButton` и `KeyboardButton`](https://core.telegram.org/bots/api#inlinekeyboardbutton), [изменения Bot API 9.4](https://core.telegram.org/bots/api-changelog).
