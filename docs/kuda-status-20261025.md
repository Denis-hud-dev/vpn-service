# Kuda Status — 25 октября 2026

## Реализация

Ветка `codex/kuda-status-20261025` строго поверх PR №22. Только premium-режим кабинета получает новый экран Kuda Status. Тёмная основа определяется темой Telegram; бот использует HTML, фирменные custom emoji и поддерживаемую синюю primary-кнопку. Произвольные цвета текста/фона не устанавливаются.

Данные: Subscription snapshot (статус, сохранённый тариф, expiry UTC и рассчитанное оставшееся время); VPN-узлы — публичные названия из тех же проверок, которые обслуживают feed Happ. Запрос не выдаёт токен и не изменяет доступ. Чужой пользователь, отозванный токен, истёкшая подписка/аренда, устаревшее здоровье или изменённая конфигурация не дают доступный узел. Это проверка допуска в подписку, а не обещание связи с телефона.

При отсутствии тарифа/даты показано отсутствие данных; при ошибке запроса узлов — временная недоступность. Нет выдуманной скорости, активности, трафика или физических устройств. Существующие второстепенные экраны доступны компактными парными кнопками. «Подключиться» открывает прежний проверенный сценарий Happ; «Продлить» только показывает тарифы. Платежи и суммы не меняются.

Гибридная навигация PR №22 сохранена: нижние кнопки создают новый экран, удаляется только предыдущий сохранённый навигационный экран. Баннер и уведомления не удаляются. Повторный /start восстанавливает ReplyKeyboard без повторного приветствия.

## Проверки

Профильные тесты охватывают активную/истёкшую/отсутствующую подписку, HTML escaping, отсутствие выдуманной статистики, отказ/тайм-аут данных узлов, разграничение владельцев, lease/health/token проверки и отсутствие создания платежа при «Продлить». Регрессии навигации, EROFS, событий, Happ и фирменных эмодзи проверяются существующими тестами. Физическую Android-проверку выполняет владелец.
