# Гибридная навигация KudaVPN Premium

Зависимая ветка `codex/premium-hybrid-navigation-20261024` основана на Draft PR №21. Изменения действуют только при пилотном флаге приветствия в `@KudaVPN_Test_Bot`; обычные inline-переходы и production-бот остаются прежними.

Три кнопки постоянной нижней клавиатуры — «🔑 Подключиться», «🏠 Личный кабинет», «ℹ️ Информация» — отправляют отдельный экран новым сообщением. У каждого нового экрана собственные inline-кнопки. Предыдущий **записанный навигационный экран** удаляется после успешной отправки и сохранения нового ID, поэтому многократные переходы не накапливают меню. Приветственный баннер, служебное сообщение с Reply Keyboard, подтверждения оплаты, продления и изменения доступа не являются навигационными экранами и не удаляются. Если Telegram не даёт удалить старый экран, бот пытается заменить его текст и убрать кнопки. Если оба действия запрещены, сохранённый ID нового экрана позволяет отвергнуть нажатие любой оставшейся старой кнопки как устаревшее. Ошибка отправки нового экрана оставляет прежний экран активным.

Личный кабинет использует существующий снимок подписки: статус, подтверждённый тариф, UTC-срок и рассчитанное по нему оставшееся время. При отсутствии срока указано «Нет данных». Количество устройств, трафик и скорость не подменяются вымышленными величинами. Подключение использует прежнюю персональную HTTPS-подписку и существующий экран Happ; ссылки не записываются в журналы.

Профильная проверка: `tests/test_pilot_welcome.py`, `tests/test_navigation.py`, `tests/test_persistent_navigation.py`, `tests/test_premium_account.py`, `tests/test_happ_link_delivery.py`. Проверяются новый ID каждого основного экрана, сохранение клавиатуры/баннера/уведомления, повторный `/start`, отказ старых callback, отказ удаления/редактирования и отправки через Telegram API, реальный срок и прежняя выдача Happ. Платежи не создаются.

Развёртывание: сохранить копию тестового unit/drop-in и текущий каталог релиза; собрать новый неизменяемый каталог приложения; сменить только `WorkingDirectory` у `kudavpn-telegram-pilot-bot.service`; перезапустить только эту службу и дождаться `/ready=200`. При ошибке вернуть прежний `WorkingDirectory` и перезапустить только тестового бота. Приватный файл состояния и все другие службы остаются на месте. Факт развёртывания и путь отката фиксируются в `WORK_SESSION_HANDOFF.md` после выполнения.
