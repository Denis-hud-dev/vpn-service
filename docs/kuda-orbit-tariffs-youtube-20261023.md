## Логотип

Действующий `kudavpn-orbit-emblem.png` — прозрачный растровый вырез той же композиции; буква K, планета и орбита в нём также не разделены. Пробное локальное редактирование меняло текстуру и пропорции планеты и не давало точного смещения одной буквы. Такой вариант отклонён и не добавлен в Git, не опубликован и не развёрнут. Для точного исправления нужен исходный многослойный/векторный файл с отдельной K либо ручная реконструкция слоя планеты с последующим утверждением владельца. Действующий знак остаётся без изменений.

## Предварительные тарифы

Telegram Bot API поддерживает у inline-кнопок только `success` (зелёный), `primary` (синий) и `danger` (красный); цвет зависит от темы клиента. Установленный aiogram 3.31.0 сериализует поле `style`. На экране «Стартовые тарифы · скоро» подготовлены зелёный месяц 190 ₽, синий квартал 490 ₽ и зелёный год 1690 ₽ со звездой. Кнопки открывают исключительно информационную карточку без платежа. Экономия относительно 190 ₽/месяц: 80 ₽ за квартал и 590 ₽ за год. Действующие платёжные тарифы 299/799/2490 ₽ и подписки не изменены. На клиентах Telegram, которые не показывают стиль, смысл сохраняют текст и пометка «скоро».

Источник: [Telegram Bot API — InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton), [Telegram — Button styles](https://core.telegram.org/api/bots/buttons).

Код опубликован в существующем [Draft PR №20](https://github.com/Denis-hud-dev/vpn-service/pull/20), коммит `4562c38`; 42 профильных теста и [CI](https://github.com/Denis-hud-dev/vpn-service/actions/runs/40069234590) прошли. Перед тестовым включением сохранена закрытая копия только bot-приложения, unit и drop-in в `/opt/kudavpn-telegram-pilot/backups/preview-tariffs-4562c38-20261023/`; откат — `/root/kuda-tariffs-rollback-4562c38.sh`. Переключён только `kudavpn-telegram-pilot-bot.service` на `app-tariffs-4562c38-bot`. После запуска служба активна, `/ready=200`, `NRestarts=0`, свежих ошибок нет. Test feed и его PID не изменились, личная подписка отвечает `200` и содержит один узел 10443; PID Xray на 443/8443/9443/10443 сохранились. Реальное отображение стилей зависит от Telegram-клиента и требует визуальной проверки владельцем на Mac/Android; автоматические тесты проверяют сериализацию `style`, навигацию и отсутствие платежного callback.

## YouTube на рабочем Wi-Fi

Проверка JustHost только на чтение: тестовый Xray 10443 активен и слушает порт, личная HTTPS-подписка отвечает `200` и содержит один тестовый узел 10443. В последние два часа в журнале службы нет записей уровня `err`. В конфигурации этого изолированного Xray нет своих DNS-серверов и правил маршрутизации, выход — `freedom`; файловые access/error-логи выключены. DNS IPv4 для YouTube на сервере работает, исходящий HTTPS `www.youtube.com/generate_204` вернул `204`. Это доказывает серверный выход, но не прохождение запроса с Android на рабочем Wi-Fi. Сервер не содержит данных, достаточных для установления точки обрыва конкретного клиентского запроса. Старая служба управления пилотным 9443 имеет состояние `failed` с 18 октября; связи с 10443 или YouTube не установлено, менять её в этой задаче нельзя.

Следующая безопасная проверка владельца: на Android с тем же профилем Happ открыть в Chrome `https://www.youtube.com/generate_204` и `https://1.1.1.1/help` сперва на рабочем Wi-Fi, затем на мобильной сети; отдельно сообщить, играет ли видео в приложении YouTube. Это различит доменный/DNS-сбой, общий сбой HTTPS-туннеля и зависимость от рабочей сети. До сравнения не менять Xray, DNS или маршруты. Если проблема проявится только в приложении, проверить, не исключён ли YouTube из VPN в настройках Happ/Android; если только на рабочем Wi-Fi — исследовать путь до 10443 из этой сети.
