28 октября 2026, America/Los_Angeles. Только открытые первичные источники. Регистрации, платные подключения и обращения провайдерам не выполнялись; ИНН владельца, доходы и клиенты не передавались. Stripe Directory недоступен в среде (нет CLI/plugin, web не читает markdown setup). Глобальные инструменты/аккаунты ради сравнения не устанавливались; ниже данные ФНС и самих организаций.

## Критерий пригодности

Нужна регистрация дохода **одного самозанятого продавца от B2C-покупок через существующую ЮKassa**, без смены эквайринга. API выплат компании исполнителям и собственный эквайринг с чеками — другие продукты. Однозначно подтверждённого turnkey cheque-only API для нашего сценария в изученных документах нет. ЮKassa не заменяется.

[Операторы ФНС](https://npd.nalog.ru/aggregators/): ООО «Самозанятые» (9731029523), ООО «Продамус» (1215156909), ООО «Консоль.ПРО» (7707418148). [Кредитные организации ФНС](https://npd.nalog.ru/credit-orgs/): Т-Банк (7710140679). Участие в информационном обмене подтверждено; пригодность конкретного API для нашей продажи этим не доказана. Поручение партнёру выдаёт налогоплательщик через «Мой налог», без передачи серверу своего пароля.

## Официальные способы

[ЮKassa](https://yookassa.ru/developers/payment-acceptance/receipts/basics) указывает: самозанятый регистрирует доход в «Моём налоге» и передаёт чек покупателю; такая опция в ЮKassa недоступна. [Changelog](https://yookassa.ru/developers/using-api/changelog), запись 23 декабря 2025: сервисы чеков/выплат для самозанятых прекращены с 29 декабря 2025. Старые статьи и прежние поля отчётов не подтверждают текущую доступность. ККТ/ОФД/54-ФЗ продукты не подменяют НПД.

Допустимы ручное формирование владельцем либо документированный API уполномоченного партнёра после договора/поручения. Собственная роль оператора ФНС требует отдельной процедуры подключения. Неофициальные API «Моего налога», scraping и хранение пароля исключены.

## Запрос кандидату — подготовлен, НЕ ОТПРАВЛЕН

«KudaVPN — собственная услуга одного самозанятого на НПД без НДС. B2C-платежи принимает наш магазин ЮKassa. Поддерживаете ли вы отдельную регистрацию дохода и корректировку чеков по внешним платежам, без вашего эквайринга и выплат исполнителям? Просим указать юрлицо из списка ФНС, договор/поручение через “Мой налог”, API/sandbox, постоянный ключ идемпотентности, lookup после timeout, асинхронные статусы, возвраты, проверку ссылки, доставку покупателю, тариф/минимальные платежи/лимиты/SLA и допустимость описанной услуги. Логин и пароль “Моего налога” передавать не будем».

Рекомендация: сохранить ЮKassa. До положительного письменного ответа и проверки API не выбирать и не оплачивать провайдера. Ни один провайдер в этой сессии не подключён.
