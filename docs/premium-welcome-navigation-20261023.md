# Пилот: первое приветствие и постоянная навигация

Ветка `codex/premium-welcome-20261023` зависит от Draft PR №20. Функция включается только при `PILOT_PREMIUM_ACCOUNT_ENABLED=1`, `PILOT_WELCOME_ENABLED=1`, пилотном маркере, ID владельца и проверенном имени `@KudaVPN_Test_Bot`. Production остаётся на прежнем коде и конфигурации.

Новому Telegram ID при первом `/start` отправляется один баннер из утверждённого прозрачного знака KudaVPN, текст и inline-кнопка «Начать пользоваться». Нажатие открывает актуальное меню. Повторный `/start` не повторяет баннер. У существующих пользователей баннер не появляется. Постоянная Reply Keyboard содержит «Подключиться», «Личный кабинет», «Информация» и не заменяет inline-кнопки экранов. Telegram не поддерживает одновременное прикрепление Reply Keyboard и inline-кнопок к одному сообщению, поэтому клавиатура устанавливается отдельным коротким сообщением. Текстовые кнопки редактируют текущий навигационный экран; приветствие и уведомления о подтверждённых событиях не удаляются.

Состояние первого запуска хранится в отдельном файле SQLite `PILOT_WELCOME_STATE_FILE` с правами 0600 вне Git и вне общей PostgreSQL. В файле только Telegram ID, ID приветственного сообщения и флаги показа/клавиатуры. Подписки, ссылки, платежи и ключи там не хранятся. Claim записывается до отправки баннера: это исключает повтор при повторном `/start`, но при сбое Telegram в момент первой отправки баннер может не появиться. В этом случае обычное меню остаётся доступным. Новых миграций общей БД нет, тестовый HTTPS-сервис не требует обновления.

Информация сообщает только подтверждённые возможности. Публичные условия использования и политика конфиденциальности в проекте не найдены и обозначены как неопубликованные. Тарифы, реальные цены, оплата и Happ-выдача не изменены.

Предпросмотр без личных данных: [приветствие](screenshots/pilot-welcome-preview.png), [нижняя клавиатура](screenshots/pilot-keyboard-preview.png). Это макеты отображения; реальные цвета и размеры кнопок выбирает клиент Telegram на Android и macOS.

## Изолированное развёртывание и откат

Перед изменением: проверить только `kudavpn-telegram-pilot-bot.service`, тестовый HTTPS `/ready` и текущий каталог bot; сохранить закрытую копию unit/drop-in, env без вывода значений, кода и конфигурации. Создать отдельную приватную папку для `PILOT_WELCOME_STATE_FILE`, не копировать её в Git. Новый код ставится в отдельный каталог, сервис переключается только на него. Проверить запуск/`/ready`, отсутствие ошибок Telegram и доступность старой персональной HTTPS-подписки без вывода URL. При неуспехе вернуть сохранённый unit/drop-in и прежний каталог bot, перезапустить только тестовый bot, проверить `/ready`. Пилотный SQLite-файл можно оставить для повторного безопасного включения; его удаление снова покажет баннеры и потому не входит в быстрый откат.

Приёмка на новом, не связанном с оплатой Telegram-аккаунте: первый `/start` → один баннер → «Начать пользоваться» → три кнопки нижнего меню; повторный `/start` → только актуальный экран. Для действующего владельца: `/start` → новая нижняя клавиатура без повторного приветствия; проверить личный кабинет, подключение, Happ-страницу и прежние тарифы. Изолированная проверка кода не создаёт подписки и платежи.

## Исправление повторного `/start`, 24 октября

Проверка запущенного тестового процесса показала релиз `app-welcome-89dc26c-bot`, оба флага Premium/Welcome включены. Прежняя логика после первой успешной отправки ставила `keyboard_installed=1` и больше не отправляла `ReplyKeyboardMarkup` на `/start`. Это объясняет невозможность восстановить скрытую или не показанную клиентом клавиатуру. При дистанционной проверке приватный файл состояния ещё не существовал; факт первой отправки клавиатуры конкретному Mac-клиенту серверными данными не подтверждён. Ошибок SQLite или отправки клавиатуры в проверенном журнале не было.

Теперь повторный `/start` всегда отправляет нижнюю клавиатуру `🔑 Подключиться` / `🏠 Личный кабинет` / `ℹ️ Информация`. Отдельная приватная таблица хранит ID только служебного сообщения клавиатуры: новое сообщение заменяет предыдущее, не удаляя приветствие, уведомления, пользовательские сообщения или навигационный экран. Действующий файл с прежней таблицей читается без миграции общей PostgreSQL. Подключение и кабинет убраны только из inline-меню тестового пилота; тарифы, Smart, устройства и помощь остались.
