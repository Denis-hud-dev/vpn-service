# KudaVPN Premium — дополнение Quiet Current

Готовы 16 новых анимированных WEBM. buy_vpn повторно использует premium, faq — support: в reused-existing лежат побайтово идентичные копии под требуемыми именами. Эти два файла повторно загружать в Telegram не нужно.

Папки:
- new-webm/ — только16 новых файлов для загрузки;
- reused-existing/ —2 справочных алиаса уже опубликованных иконок;
- source/ —16 редактируемых SVG и описания;
- png/ —контрольные кадры, не замена анимации;
- preview/index.html —живой WebM-предпросмотр, переключение светлой/тёмной темы и пауза;
- preview/animated-grid.gif —анимированная обзорная сетка;
- preview/contact-sheet.png —сравнение и размеров20/24/32px;
- mapping.csv / manifest.json —назначение, кнопка, настоящий существующий ID или пустое значение;
- verification.json —результат реального декодирования18 WEBM.

Как добавить в существующий набор:
1. Откройте официальный @Stickers: https://t.me/Stickers и его мини-приложение управления наборами.
2. Выберите принадлежащий вам набор KudaVPNPremium (https://t.me/addemoji/KudaVPNPremium), затем добавление элементов. Если доступен только текстовый интерфейс, следуйте подсказкам бота для редактирования существующего набора — новый набор создавать не нужно.
3. Загружайте по одному только файлы из new-webm/ как документы в исходном качестве, без преобразования в GIF/обычное видео. Для смысловой привязки используйте alt из manifest.json и таблицы ниже.
4. Проверьте проигрывание на телефоне. Не загружайте reused-existing повторно.
5. После загрузки настоящие custom_emoji_id получают поддерживаемым Bot API getStickerSet(name=KudaVPNPremium), затем сопоставляют с образцами и таблицей; одного Unicode-символа/порядка недостаточно для надёжного сопоставления. Секретный токен в чат не передавать.
6. Новые16 ID пока пусты. Интеграция и изменение работающих кнопок возможны только после подтверждения владельца. Сейчас ничего в бот не подключено.

Параметры: VP9 WebM,100×100,24fps,2s,48 кадров,без аудио. Прозрачный фон вокруг исходной графитовой плитки; сама плитка сохранена как в оригинальных14. Голубой55D6FF, ледянойD9F7FF, графит111A22, контур315165. Медленно движется только орбитальная точка; символы не вращаются.

Официальные требования Telegram: https://core.telegram.org/stickers/webm-vp9-encoding —ровно100×100,до30fps,до3s,VP9,без аудио,до256KB,плавный цикл. Файлы здесь5999–6724байта. Публикация в Telegram пока не выполнялась.

Оригинальные14 файлов в Downloads/KudaVPN-Premium-emoji-webm не изменялись, SHA256 каждого совпал с коммитом b630c3b. Все14 действующих custom_emoji_id сохранены в manifest.json. Apple, iOS и macOS различаются формой: отдельный знак, телефон и экран; referral —приглашение с плюсом, community —группа. promo отличается от gift купоном со знаком процента.

Воспроизводимость: исходный renderer найден в Git b630c3b:scripts/generate_premium_emoji.py. Из него без перерисовки перенесены только геометрия/рендеринг/кодек в scripts/emoji_legacy_renderer.py; генерации старых14 в новом модуле нет. Новый build_emoji_extension.py создаёт только16 новых фигур и копирует2 оригинала, сверяя SHA256 всех14. SVG доступны для редактирования. Генераторы в приложенной source/generators —снимки исходников; запуск сборки предназначен из полного репозитория в отдельной рабочей папке. Требуются Pillow и imageio-ffmpeg; боевые секреты и серверы не нужны. Защита от неявной перезаписи экспортов включена.
